# English in Content

[English](README.md)

English in Content 是一个用真实视频和文章学习英语的工具. 词和表达来自酒店介绍, 科技视频, 访谈和文章. 学习时先看英文, 想看中文再自己点开.

## 下载和使用

1. 下载 ZIP 压缩包: [main.zip](https://github.com/KaynXu/english-in-content/archive/refs/heads/main.zip)
2. 解压得到文件夹.
3. 用 Chrome 或 Edge 打开文件夹里的 index.html.

不需要账号, API Key, Git, Python, Node 或终端. 图片和音频文件已在文件夹中. 原视频链接需要网络才能打开.

## 学习

### 首页

点击视频封面进入词卡.

### 视频词卡

每张卡先显示英语句子. 点击卡片或按空格键看中文. 按左右方向键换卡. 按 Enter 重播发音. 按 G 把词标为绿色, 按 Y 把词标为黄色.

### 文章

点击首页 Articles 进入文章. 鼠标悬停在标注词上, 可以看到词条, 美式音标和英文意思. 点击标注词, 打开中文释义和文章批注. 在预览或弹窗打开时, 空格键发音, G 标绿, Y 标黄, Esc 关闭.

黄词带黄色下划线, 表示还需复习. 绿词带绿色下划线, 表示已经掌握. 同一个词在不同材料里共享学习状态, 但每篇材料保留自己的语境释义.

## 保存学习记录

在 Library 页面点击 Enable autosave, 选择当前解压文件夹里的 vocabulary.js. 这是浏览器保存文件需要的一次授权. 没有授权的改动在关闭页面后会丢失. 请使用 Chrome 或 Edge.

## 听写

Quiz 页面可以选择材料练听写. 播放发音后用键盘输入听到的单词. Enter 重播. Daily 页面在绿词达到 10 个以后开放. 新下载的示例中, 所有词从黄色开始.

## 添加自己的内容

如果你会用能编辑本地文件的 AI 助手, 可以打开这个项目文件夹, 发给它网页或 YouTube 链接, 让它按照 AGENTS.md 制作新材料, 并保留 vocabulary.js 里的学习记录. 使用现有示例不需要 AI.
